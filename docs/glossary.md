# Glossary

- **PWA:** A web app that can be installed on a device Home Screen.
- **Service Worker:** Background browser code that receives push events and displays notifications.
- **VAPID:** Keys and claims that identify the application server to a push service.
- **PushSubscription:** The endpoint and encryption keys issued for a browser installation.
- **Quick Tunnel:** A temporary public HTTPS route to the local development server.
