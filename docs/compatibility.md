# Compatibility

- iOS and iPadOS 16.4 or newer are required for Home Screen Web Push.
- The PWA must be installed from Safari before notification permission is requested.
- Windows 10 or 11 can run the Rust sender and Cloudflare tunnel.
- A current Chromium browser is useful for desktop diagnostics, but does not prove iPhone delivery.

Always validate the final notification on a physical, locked or backgrounded iPhone.
